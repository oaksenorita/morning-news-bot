厳選ビジネスニュース

8月機械受注5.2％増 2カ月ぶりプラス

ロジカル要約
  • 背景/経緯: 企業の設備投資姿勢を見極める先行指標として機械受注統計が注目される中、前月は反落していた。
  • 事象: 内閣府が発表した8月の機械受注統計（船舶・電力を除く民需）は、前月比5.2％増となり2カ月ぶりのプラスを記録。
  • 結果/影響: 製造業・非製造業ともに底堅い設備投資需要が確認され、国内景気の緩やかな回復基調を裏付ける結果となった。
地銀視点の深掘り

北海道内でも人手不足への対応を目的とした省力化・自動化投資や、老朽化設備の更新需要が活発化しています。取引先の中小企業を訪問する際は、「設備投資の計画や補助金の活用予定はございますか？」といったヒアリングから、設備資金調達や日本公庫等との協調融資、リース提案への糸口を掴む会話ネタとして活用できます。

世界最高レベルの低NOX性能実現に見通し…川重、水素航空エンジンで試験成功

ロジカル要約
  • 背景/経緯: 航空業界における2050年カーボンニュートラル達成に向け、次世代クリーンエネルギーである水素エンジンの開発競争が激化している。
  • 事象: 川崎重工業が水素混焼・専焼航空機用エンジン燃焼器の燃焼試験を実施し、世界最高水準の低NOx（窒素酸化物）性能の実現に見通しを立てた。
  • 結果/影響: 航空分野での脱炭素技術の実用化が前進し、関連サプライチェーンや水素インフラの整備計画への追い風となる。
地銀視点の深掘り

北海道は苫小牧や室蘭を中心に「水素サプライチェーン拠点化」や再生可能エネルギー活用を進めており、道内経済にとっても水素関連技術の進展は直結する重要テーマです。エネルギー関連企業やものづくり企業との面談時には、GX（グリーントランスフォーメーション）や脱炭素投資への取り組み状況を伺うフックとして大いに役立ちます。

墓じまいをしようと思っています。「50万円あればできる」と聞きましたが、墓石の撤去以外にもお金がかかるのでしょうか？ 費用相場も知りたいです。

ロジカル要約
  • 背景/経緯: 少子高齢化や核家族化に伴い、遠方にある先祖代々の墓の維持管理が難しくなり、「墓じまい」を検討する世帯が急増。
  • 事象: 単なる墓石撤去（約10万〜30万円）にとどまらず、離檀料、閉眼供養のお布施、新たな受入先（永代供養墓・樹木葬・納骨堂等）への納骨費用など、総額で数十万〜数百万円規模の費用が発生する実情が解説された。
  • 結果/影響: 高齢者世代における想定外の出費要因となり、事前のライフプランニングや資金準備の重要性が浮き彫りとなっている。
地銀視点の深掘り

道内は過疎化・高齢化が顕著であり、リテール（個人）営業において「終活・生前整理・相続対策」は極めて関心の高い話題です。窓口や営業先で高齢のお客様と接する際、預貯金の保全だけでなく、遺言信託や資産承継、家族信託といった当行のソリューションを案内するための身近なアプローチ題材となります。
