ロジカル要約
  • 背景/経緯: モビリティ業界が変革期（CASE・脱炭素化）を迎える中、単独企業での課題解決が難しくなり、異業種連携やオープンイノベーションの必要性が急務となっている。
  • 事象: 「ジャパンモビリティショー（JMS）ビズウィーク2026」において、リアルとオンラインを融合させた参加型プログラムが多数企画され、スタートアップと既存大企業・異業種との接点を創出。
  • 結果/影響: 従来の展示型イベントから実効的な共創創出型へシフト。道内を含む地方の中小ものづくり企業やITベンダーにとっても、中央企業とのアライアンスや新規事業参入の好機が広がる。
地銀視点の深掘り

北海道内でもEVインフラ整備や観光型MaaS、寒冷地特有の自動運転実証実験などに取り組む取引先が増加しています。ものづくり企業だけでなく、ソフトウェア開発や物流企業のお客様に対して「異業種共創に向けたネットワーキング」の話題を投げかけることで、新規事業投資やビジネスマッチング需要の掘り起こしに繋がります。
