個人金融・住宅ローン・雇用動向

【世帯年収】共働き世帯は「1333万世帯」で専業主婦世帯の2.8倍に。9月の配偶者の収入は月9万8001円に上がった

ロジカル要約
  • 背景/経緯: 物価高への対応や社会構造の変化により、夫婦共に収入を得る共働きモデルが標準化。「年収の壁」見直し論議も活発化している。
  • 事象: 共働き世帯数が1333万世帯に達し専業主婦世帯（約470万世帯）の2.8倍に拡大。配偶者（主に妻）の平均月収も9万8,001円へ伸長した。
  • 結果/影響: 世帯収入の合算により住宅購入等の借入余力が増加する一方、税制や社会保険料負担の境界線に対する家計の関心が一層高まっている。
地銀視点の深掘り

道内でも住宅ローン提案において「ペアローン」や「夫婦連帯債務」のニーズが定番化しています。また、道内中小企業の人手不足対策（主婦パートの労働時間拡大）と直結する話題です。リテール営業では、共働き世帯向けの新NISA・教育資金形成サポートのフックとして、また法人営業では取引先のパート採用・時給改定動向をヒアリングする好材料になります。

道内産業・飲食・一次産業振興

日本人のボジョレー・ヌーヴォー好きは教科書に載るほど？ ワイン界で今起きている変化

ロジカル要約
  • 背景/経緯: かつてバブル期や2000年代に一大ブームとなったボジョレー・ヌーヴォー（毎年11月第3木曜日が解禁日）。本日はその解禁日当日。
  • 事象: 円安や輸送コスト高騰を受け、輸入イベントとしての一律のお祭り騒ぎから、品質重視や国内ワイナリーへのシフトなど消費行動が多様化。
  • 結果/影響: 日本ワイン（特に冷涼な気候を活かした北海道産ワイン）の評価が国際的に向上し、地産地消や観光（ワイナリーツーリズム）と融合した新市場が形成されている。
地銀視点の深掘り

本日（11月第3木曜日）はまさに解禁日であり、飲食業や小売業の取引先との雑談に即効性があります。さらに北海道（余市、空知、池田町など）は今や世界的ワイン産地として投資が活発です。地銀としては単なるブーム消費の話題にとどまらず、地元ワイナリーの設備資金調達、寒冷地農業の高付加価値化、インバウンドを絡めたアグリツーリズム支援といった事業性評価の視点を持って議論を深められます。
