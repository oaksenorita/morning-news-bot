厳選ビジネストピックス

全固体電池はまだ「実証段階」、それでも材料市場は急拡大　日中韓が供給網構築

ロジカル要約
  • 背景/経緯: EVの航続距離延伸や安全性向上を目指し、次世代バッテリーである「全固体電池」の商用化競争が世界中で激化している。
  • 事象: 完成品の本格量産は依然として実証段階にあるものの、固体電解質や正極・負極材など周辺の材料市場が先行して急拡大し、日中韓でサプライチェーン構築が加速している。
  • 結果/影響: 最終製品の登場を待たずに部素材メーカーへの投資や提携が活発化しており、化学・素材セクターの設備投資需要が高まっている。
地銀視点の深掘り

北海道は冬期の寒冷環境によるEVバッテリー性能低下が課題とされており、低温環境下でも安定動作が期待される全固体電池への期待は極めて高い分野です。道内の素材加工・リサイクル関連企業への波及効果や、大規模再エネ（風力・太陽光）と組み合わせた系統用蓄電池ビジネスの可能性について、融資先メーカーや自治体担当者と意見交換する格好のテーマになります。

続きを読む

BYD、上半期は減収減益　海外売上が初めて中国国内を上回る

ロジカル要約
  • 背景/経緯: 中国国内市場での熾烈なEV価格競争（値下げ合戦）と景気減速により、自動車メーカー各社の収益性が圧迫されている。
  • 事象: 中国EV大手BYDの上半期決算は減収減益となった一方、海外市場向けの販売比率が伸長し、海外売上高が初めて中国本土の売上を逆転した。
  • 結果/影響: 中国勢の内需依存から海外シフト（東南アジア・欧州・日本等）が一層強まり、日本国内の自動車サプライチェーンや輸入車ディーラー市場への影響拡大が予測される。
地銀視点の深掘り

道内でもバス会社など公共交通機関や商用車領域でBYD製EVの導入事例が増加しています。自動車関連の裾野が広い取引先（自動車整備業、部品商社、ガソリンスタンド経営企業など）に対し、EVシフトの進展度合いや充電インフラ整備の動向、脱炭素経営（トランジション・ファイナンス）の支援に向けた有益な対話のきっかけになります。

続きを読む

180億円相当還元「かなトク！」9月6日で終了。ポイント付与後の注意点を解説

ロジカル要約
  • 背景/経緯: 物価高対策および地域経済活性化・キャッシュレス推進を目的に、神奈川県が総額180億円規模の大規模還元キャンペーンを展開。
  • 事象: 予算上限到達に伴い9月6日での前倒し終了が決定。付与されたポイントの有効期限や失効防止策への注意喚起が行われている。
  • 結果/影響: 駆け込み需要の発生とともに、キャンペーン終了後の消費反動減への対策や、恒常的なキャッシュレス利用定着が課題となっている。
地銀視点の深掘り

道内の各市町村でも「プレミアム付き商品券」や「デジタル地域通貨」を活用した地域活性化事業が数多く行われています。地方銀行は自治体主導の消費喚起策の事務局受託や、キャッシュレス決済端末の導入支援を担うキープレイヤーです。キャンペーン終了後の顧客囲い込みやDX推進策について、道内小売・飲食業の取引先へ提案する際の参考事例として活用できます。
