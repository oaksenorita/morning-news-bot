📰 注目ニュース＆業務深掘り (3選)

円急伸、一時157円24銭 2日連続の為替介入か

ロジカル要約

  • 背景/経緯: 歴史的な円安水準の継続に伴い、輸入コストの高騰や国内インフレへの懸念が高まっていた。
  • 事象: 米ドル/円相場が急伸し、一時157円24銭まで円高に振れた。政府・日銀による2日連続の為替介入（覆面介入）の可能性が指摘されている。
  • 結果/影響: 短期的な為替ボラティリティの上昇に伴い、輸出入企業や外貨建て資産を保有する個人の資産価値に大きな変動が生じている。

地銀視点の深掘り

法人担当（RM）として、道内の輸出入事業者（水産物・農産物の輸出企業や燃料・資材の輸入企業）を訪問する際の絶好の会話ネタになります。「為替が急変動していますが、調達コストや採算への影響はいかがですか？」とアプローチし、為替予約や外貨建融資、リスクヘッジ手法の提案へと繋げましょう。

続きを読む

学資保険とNISAで教育費を貯めるのとでは、どちらがおトクですか？ 返戻率と節税も含めて教えてください。

ロジカル要約

  • 背景/経緯: 教育費負担の増大を受け、子育て世代における効率的な資金形成手法への関心が強まっている。
  • 事象: 万が一の保障と元本確実性を重視する「学資保険」と、非課税メリットと運用効率を狙う「新NISA（つみたて投資枠など）」の比較検討が行われている。
  • 結果/影響: 単一の商品に頼るのではなく、リスク許容度や資金ニーズの時期に合わせたポートフォリオ選択が重視されるようになっている。

地銀視点の深掘り

リテール窓口や推進において、子育て世代の顧客から頻繁に受ける相談テーマです。「元本確保と保障なら保険、インフレ対策と運用益なら積立NISA」という整理をした上で、両者を組み合わせた分散提案を行うことが有効です。当行の積立投資信託や平準払保険のクロスセルに向けた会話の口火として活用できます。

続きを読む

遺族厚生年金をもらいながら、自分の老齢厚生年金をもらう年齢（65歳）になりました。両方とも全額もらえると思っていたのに、遺族厚生年金が減るって損じゃないですか？

ロジカル要約

  • 背景/経緯: 公的年金制度の併給調整ルールにより、65歳到達時には自身の老齢厚生年金の受給が優先される仕組みになっている。
  • 事象: 自分の老齢厚生年金が全額支給される一方、遺族厚生年金からはその同額分が支給停止（差額支給）されるため、「受給額が減らされた」と誤解されやすい。
  • 結果/影響: 実際の総受給額自体は維持または増加するものの、仕組みの複雑さから不満や困惑を感じる高齢者が多い。

地銀視点の深掘り

シニア層顧客との関係構築や、年金受給口座の指定獲得（年金振込キャンペーン等）の場面で必須となる知識です。65歳を迎える顧客に対し、年金額の支給内訳を正確にわかりやすく説明することで高い信頼を得られます。さらにそこから、老後資金の取り崩しシミュレーションや、遺産相続・遺言信託など総合金融サービスの提案へと展開しましょう。
