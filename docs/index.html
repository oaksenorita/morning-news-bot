  • 背景/経緯: フィンテック企業（Payme）のCOOを務めた経営人材が、伝統的な地域インフラである「銭湯」ビジネスの可能性に着目した。

  • 結果/影響: IT業界のマーケティングや組織作りのノウハウとリアルな地域・コミュニティ体験を融合させることで、新たな集客モデルとブランド価値を創出した。

地銀視点の深掘り
